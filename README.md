# Microprocessor LAB

8051 微處理機課程實驗，包含組合語言與C。

## 實驗內容

| 檔案 | 語言 | 內容 |
|---|---|---|
| `lab4.A51` | A51 組語 | 從程式記憶體以 `MOVC` 讀取資料表，對雙位元組數值做加、減、乘運算，加法以 `ADDC` 處理進位、減法以 `SUBB` 處理借位 |
| `lab5.A51` | A51 組語 | 泡沫排序，以間接定址 `@R0` / `@R1` 逐一比較相鄰元素，用 `DJNZ` 控制雙層迴圈 |
| `lab6.A51` | A51 組語 | 以 P2 讀取指撥開關狀態，用 `CJNE` 分支，依不同組合呼叫前幾個 lab 的副程式 |
| `lab7.c` | C | 以 `_crol_` / `_cror_` 內建函式實作 LED 位移動畫，依 P2 開關組合切換不同花樣 |
| `lab8.c` | C | 四位元計算機。以 `sbit` 分別讀取 A、B 兩組指撥開關，按鍵切換加、減、AND、OR 四種運算並輸出至 P0 |
| `lab9.c` | C | 七段顯示器上下限計數。以兩個開關組合切換設定上限、設定下限、上數、下數四種模式，並在到達邊界時循環 |
| `lab10.c` | C | 4×4 矩陣鍵盤計算機。掃描鍵盤取得數字與運算子，將結果顯示於七段顯示器，超出範圍時顯示錯誤碼 |
| `lab11.c` | C | 外部中斷控制。`INT0` 切換 LED 花樣、`INT1` 切換播放速度，主迴圈依狀態陣列循環播放並將目前狀態顯示於七段顯示器 |

## 共用

- **`kb44.h`** — 4×4 矩陣鍵盤掃描。逐列拉低掃描線後讀取行狀態，偵測到按下時延遲消除彈跳，並等待放開後才回傳鍵值，避免重複觸發
- **`reg51.h`** / **`intrins.h`** — Keil C51 提供的暫存器定義與內建函式

## 使用技術

- 8051 組合語言：間接定址、程式記憶體查表、進位／借位運算、迴圈控制
- Keil C51：`sbit` 位元定址、外部中斷（`TCON` / `IE` 設定）、七段顯示器共陽極編碼表
- 硬體介面：指撥開關輸入、LED 輸出、七段顯示器、4×4 矩陣鍵盤
